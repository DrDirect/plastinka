# Telegram Bot - Album Cover Video Note Generator

Рабочая версия бота для создания круглых видеосообщений (video note) из MP3 файлов.

## Описание

Бот принимает MP3 файлы и автоматически:
1. Извлекает обложку альбома из MP3
2. Создает обложку с использованием шаблона `base.png`
3. Извлекает случайный 60-секундный фрагмент аудио
4. Создает видео с вращающейся обложкой
5. Отправляет результат как круглое видеосообщение (video note) со звуком

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что установлен `ffmpeg`:
- Windows: скачайте с https://ffmpeg.org/download.html
- Linux: `sudo apt-get install ffmpeg`
- macOS: `brew install ffmpeg`

3. Запустите бота:
```bash
python telegram_bot.py
```

## Конфигурация

В файле `telegram_bot.py` найдите переменную `BOT_TOKEN` и замените на свой токен бота.

## Важные параметры кодирования видео

Видео кодируется с параметрами, близкими к записи с камеры Telegram:
- **Профиль H.264**: baseline
- **Качество**: CRF 28
- **Аудио**: AAC, 44100 Hz, стерео, 96k битрейт
- **Частота кадров**: 30 fps
- **Разрешение**: 640x640 пикселей
- **Формат**: MP4

## Требования

- Python 3.8+
- ffmpeg
- Pillow
- mutagen
- python-telegram-bot
- requests

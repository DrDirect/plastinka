# Рабочая версия - сохранена 18 декабря 2025

## Ключевые особенности этой версии

✅ **Работает корректно**: Video note со звуком отправляется правильно

### Исправленные параметры кодирования

Параметры ffmpeg настроены для совместимости с Telegram video note:

```python
'-profile:v', 'baseline',  # Базовый профиль (как у мобильных камер)
'-level', '3.1',
'-crf', '28',  # Баланс между качеством и размером
'-preset', 'medium',
'-maxrate', '2M',
'-bufsize', '4M',
'-c:a', 'aac',
'-b:a', '96k',
'-ar', '44100',  # Стандартная частота дискретизации
'-ac', '2',  # Стерео
'-pix_fmt', 'yuv420p',
'-r', '30',  # 30 fps
'-g', '30',  # GOP size
'-f', 'mp4',
```

### Метод отправки

Используется прямой вызов Telegram Bot API через `requests` с методом `sendVideoNote`:
- Файл передается через `multipart/form-data`
- Параметр называется `video_note`
- Указываются `duration` и `length` (размер в пикселях)

### Известные рабочие параметры

- Разрешение: 640x640 пикселей
- Максимальная длительность: 60 секунд
- Максимальный размер файла: до 8 МБ (ограничение Telegram для video note)
- Формат: MP4 (H.264 + AAC)

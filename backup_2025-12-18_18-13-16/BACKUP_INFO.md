# Бекап версии

**Дата создания:** 2025-12-18 18:13:16

## Изменения в этой версии

- Частота кадров изменена на 60 fps
- GOP size обновлен до 60 (1 секунда при 60 fps)
- Убраны все промежуточные сообщения о стадиях обработки
- Добавлена поддержка треков короче 60 секунд (используется весь трек)
- Параметры кодирования настроены для корректной работы video note со звуком

## Параметры кодирования

- **Профиль H.264**: baseline
- **Качество**: CRF 28
- **Частота кадров**: 60 fps
- **GOP size**: 60
- **Аудио**: AAC, 44100 Hz, стерео, 96k битрейт
- **Разрешение**: 640x640 пикселей
- **Формат**: MP4

## Функциональность

- Автоматическое извлечение обложки из MP3
- Создание обложки с шаблоном base.png
- Вырезание случайного 60-секундного отрезка (или весь трек, если короче 60 сек)
- Создание видео с вращающейся обложкой
- Отправка как круглое видеосообщение (video note) со звуком
- Без промежуточных сообщений о стадиях обработки
